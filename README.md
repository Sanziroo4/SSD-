# SSD.LAB

SSD технологиясын қазақ тілінде түсіндіретін интерактивті сайт. React, Vite және Three.js негізінде жасалған. Серверлік API, аккаунт немесе құпия кілт қажет емес.

## Іске қосу

### Бағдарлама орнатпай көру

`npm run export:html` сайтты `exports/SSD-LAB.html` деген бір файлға жинайды. Сол файлды компьютерге сақтап, Chrome, Edge немесе Firefox браузерінде ашуға болады. Шрифттер мен JavaScript файлдың өзіне енгізіледі; Node.js, жергілікті сервер және интернет байланысы сайтты көру үшін қажет емес. 3D үшін браузерде WebGL қосулы болуы керек.

Бұл файлды жасау үшін төмендегі Node.js ортасы қажет, бірақ дайын HTML-ді ашу үшін қажет емес. Бұлттағы файлдар, GitHub-тағы код және интернетте жарияланған сайт — үш бөлек нәрсе: жергілікті өзгерістер GitHub-қа автоматты түрде жіберілмейді, ал ортаны жариялау веб-сайтқа жалпыға ашық адрес бермейді.

### Әзірлеу режимі

Node.js 22.12+ немесе 24 LTS қажет.

GitHub Pages нұсқасы `main` тармағының `/docs` каталогынан жарияланады. Сайтты өзгерткеннен кейін `npm run export:html` орындаңыз: ол браузерде ашылатын жеке HTML-мен бірге `docs/index.html` файлын жаңартады. Бастапқы React жобасы түбірде, ал жарияланатын жинақ `docs/` ішінде сақталады.

```sh
cd /workspace/SSD-
npm ci
npm run dev -- --port 5173
```

`npm run build` өндірістік нұсқаны `dist/` каталогына жинайды. Оны кез келген статикалық хостингке орналастыруға болады. `npm run preview` дайын жинақты жергілікті тексеруге арналған.

## Сайттың мүмкіндіктері

- Кеңістікте қалықтайтын, меңзермен бұрылатын SSD моделі.
- Анимациямен бөлшектеу және қайта жинау. Алты компонентті меңзермен немесе компонент батырмаларымен зерттеу.
- HDD және SSD принциптерін көрнекі салыстыру.
- Файлды таңдап, жазу мен оқу жолын кезеңдер бойынша көру.
- NAND, TRIM, TBW, SLC кэш және сыйымдылық бірліктері туралы алты интерактивті факт.
- Скроллмен пайда болатын бөлімдер, оқу прогресі, телефон мәзірі және сұрақ-жауаптар.
- `prefers-reduced-motion` баптауын ескеру. Шрифттер жергілікті пакеттен беріледі; сыртқы CDN қажет емес.

3D көрініс үшін браузерде WebGL болуы керек. WebGL қолжетімсіз болса, құрылғының қарапайым балама көрінісі беріледі; компоненттерді батырмалар арқылы зерттеуге болады. Модель мен симуляция оқу мақсатында жеңілдетілген. Жеке DRAM мен радиатор барлық SSD-де болмайды; көрсетілген жылдамдық барлық SSD-ге ортақ емес.

## Тексеру

```sh
npm run build
npm test
```

Playwright бес сценарийді тексереді: навигация және HDD/SSD ауыстыруы; алты бөлшек пен қайта жинау; жазу/оқу және файлды өзгерту; фактілер мен сұрақ-жауаптар; телефон мәзірі мен экранға сыйуы. Бұл ортада жүйелік Chromium автоматты түрде пайдаланылады. Басқа компьютерде `npx playwright install chromium` орындаңыз немесе `CHROMIUM_PATH` арқылы браузер жолын көрсетіңіз. Тесттер серверді өздері іске қосады, не 5173 портындағы бар серверді пайдаланады.

## Файлдар

- `src/App.jsx` — бөлімдер мен интерактивтер.
- `src/components/SSDScene.jsx` — нақты уақытта салынатын үш өлшемді модель, жарық және анимация.
- `src/data.js` — қазақша түсіндірмелер мен фактілер.
- `src/styles.css`, `src/motion.css` — бейімделетін дизайн және қозғалыс.
- `e2e/smoke.spec.js` — браузердегі функционал тексерулер.

Бұлттағы әр тапсырма оқшауланған ортада орындалады. Бар `/workspace/SSD-` checkout-ында жұмыс істеңіз; пайдаланушы арнайы сұрамаса, қосымша Git worktree құрмаңыз.
